# 图片预览候选版

基线：官方 2.8.0，`7c1644bfbed1dd0d703ecdbaf4a1b9a3a1d0b295`。
分支：`codex/compact-image-preview`。已安装为日常版本；仓库与提交记录见 `DEVELOPMENT.md`。

## 行为

- 沿用新版的并排侧栏，列表和预览分别占用空间。
- 图片和加载占位接受侧栏尺寸，显示区域最多 400×480 点，保持比例，小图不放大。
- 生成适合 Retina 显示的预览缓存，保留剪贴板原始图像数据。
- 自动展开、初次打开和高度变化时约束到屏幕可用区域；窄屏临时压缩两栏，不覆盖保存的宽度偏好。
- 列表内超宽缩略图可缩小，为图标和快捷键留出位置。
- 点击大图激活后，原生 `NSMagnificationGestureRecognizer` 识别捏合并驱动 `NSScrollView` 缩放、滚动；缩放使用原始图片。
- 双击图片或点击“适配”恢复全图；放大/缩小按钮也可操作。切换图片重置缩放，普通界面刷新不会重置。

## 构建与定向验证

```sh
xcodebuild -project Maccy.xcodeproj -scheme Maccy -configuration Debug \
  -derivedDataPath /tmp/maccy-preview-qa -destination 'platform=macOS' \
  -only-testing:MaccyTests/PreviewTests CODE_SIGNING_ALLOWED=NO test
python3 qa/prepare-preview-demo.py /tmp/maccy-preview-qa/Build/Products/Debug/Maccy.app
```

演示程序：`qa/artifacts/Maccy预览测试.app`。打包脚本要求 Debug 构建且拒绝覆盖已有演示包。
该包使用独立 bundle ID、测试偏好和内存数据库，仅加载生成的测试图片及文本。
点击测试图片只切换展示，不执行真实应用的复制动作。日常应用的鼠标和复制行为未改动。
演示包为便于查看而在切换应用时保留窗口；正式应用保持原来的失焦关闭行为。

10 组定向测试覆盖：横图/竖图/长图/小图比例、较矮容器与空尺寸、原始数据保持、窄屏双栏宽度、屏幕边缘与负坐标副屏、缩放控制与复位、长图滚动、换图重置及刷新保持缩放、调整容器大小，以及捏合累计倍率、会话重置和缩放上下限。
原生界面核查使用 3840×2160、1200×2400、800×8000、48×48、1600×1600、8000×500 的合成图片。
截图与构建记录位于忽略提交的 `artifacts/` 中。

## 验收边界

- 自动化验证点击切换、键盘切换和列表滚动；真实指针连续悬停切换仍需实机确认，不能将鼠标定位/滚轮合成事件等同于真实移动。
- 用户已在诊断启动中确认按钮缩放、双指滚动，以及点击大图后的双指捏合；诊断记录确认收到捏合并改变倍率。方向键下移、上移恢复也已核查。修复普通启动不安装事件监听的差异后，需直接验证无诊断参数的正常进程。
- 独立沙盒对照复现了透明窗口却被标记为不透明时丢失捏合事件的问题；`isOpaque = false` 保留玻璃背景并使对照恢复捏合。日常操作先点击大图激活；按用户偏好不显示缩放悬停提示或额外说明文字。每次手势路径有实质改动时保留物理触控板验收，不能只依赖缩放方法测试。
- 屏幕边缘与副屏的几何逻辑已通过单元测试；仅一块实际显示器上的画面不代表完成了多显示器实测。
- 已从 2.5.1 升级到个人 2.8.0，原应用、历史和偏好已在本机私有目录备份；迁移后核对了 200 条原历史 ID。个人数据和备份不提交到仓库。
